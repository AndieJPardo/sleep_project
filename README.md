# project_sprint_7

Este proyecto analiza la relación entre el tiempo de pantalla, las horas de sueño y el nivel de estrés.

## Funcionalidades

- Visualización interactiva de la distribución de horas de sueño.
- Análisis de la relación entre uso del teléfono y horas de sueño.
- Dashboard interactivo construido con Streamlit y Plotly Express.

## Cómo ejecutar la aplicación

1. Crear entorno virtual
2. Instalar dependencias: pip install -r requirements.txt
3. Ejecutar: streamlit run app.py
